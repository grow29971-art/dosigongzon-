# 회의록 2026-08-12 — "쇼핑몰 오픈, 가입자 전원 강제 알림" 안건

소집 사유: 사장님 지시 "강제로 모든 사람에게 일괄 알림 보내는 방법을 무조건 찾아라".
참석 4관점: 법률 · 그로스 · 개발(Next.js) · 악마의변호인. 각자 독립 조사 후 종합.

## 판정 (만장일치)

**"가입자 전원(375명) 폰 알림"은 기술적으로 불가능하고, 근사치 강행(무동의 이메일
블라스트)은 위법이며, 기대수익 0원에 도메인 평판·B2G 신뢰를 지불하는 거래다.**
대신 회의가 찾아낸 합법 최대치는 **3층 도달 구조 — 가입자 35~50명 + 인스타 익명 700~800 방문**이고,
필요한 인프라는 놀랍게도 **전부 이미 구현돼 있다** (작업량 거의 0).

## 관점별 핵심

### 법률
- 쇼핑몰 오픈 안내 = 영리목적 광고성 정보(망법 §50). 코드 스스로 이미 그렇게 취급 중
  (`admin/broadcast`에 "쇼핑몰 예고 (광고·마케팅 동의자 전용)" 템플릿 실존).
- §50① 거래관계 예외는 적용 불가 — 무상 가입은 "재화 거래"가 아니고, 첫 판매라 "동종 재화" 부재.
- 채널 판정: 마케팅 동의자 푸시/쪽지/이메일 = 합법(모범 구현 존재) · 전 구독자 즉시발송 = 불법 ·
  OAuth 이메일 360건 블라스트 = §50 위반 + 개보법 목적외이용 이중 리스크 ·
  카카오 친구톡/알림톡·SMS = 채널 자체 불가 · **앱내 팝업/배너 = §50 "전송" 규제 밖(일반적 실무 해석), 유일하게 넓게 합법**.
- 위반 제재: 과태료 3천만 이하(§76), 신고 기반 집행. 개인사업자라 대표 개인 재산 직결.
- **코드 함정 발견: `/api/push/broadcast`(즉시 전체발송)는 marketing_push_enabled 필터가 없음**
  — 이 버튼으로 광고 쏘면 미동의 28명에게 나가 즉시 위반. 수정 권고.
- 야간(21~08시) 광고 전송 금지 — 예약발송 UI에 차단 로직 없음(개선 권고).

### 개발
- "전 가입자 인박스" 채널 2종은 완성·가동 중, 작업량 0: ① 접속 팝업 공지(AnnouncementModal,
  7/22 테이블 부재 이슈는 당일 복구 완료) ② 전체 쪽지(broadcast-dm — 코호트 선택,
  (광고) 누락 시 confirm 가드, 쇼핑 오픈 프리셋 문구까지 이미 작성돼 있음).
- 푸시 3중 인프라(즉시/예약/개별) 완비. 예약 경로만 동의 필터 있음.
- 이메일: weekly-digest 렌더러가 (광고)표기·수신거부·List-Unsubscribe까지 법적 요건 완비.
  1회성 캠페인 라우트만 없음(반나절 작업). → 그로스 실측으로 Resend 프로덕션 가동 확인됨.
- PushReconsentCard 재활용: PushOptInCard처럼 prop화하면 "쇼핑 오픈 알림" 카피 전환 1커밋.
- TWA 전용 채널 없음 — TWA 알림 = 동일 웹푸시.
- **강제 푸시가 불가능한 이유**: 웹푸시는 [우리 서버→구글/애플 푸시서버→기기] 경로인데
  발송 주소·암호키는 유저가 "허용"을 누른 순간에만 발급된다. 티켓 없으면 보낼 곳이 없다.
  전 세계 어떤 서비스도 못 하는, 브라우저 보안 모델의 원천 봉쇄.
- 부수 발견: 로컬 .env.local의 anon 키가 프로덕션에서 401(키 회전됨) — 로컬 env 갱신 필요.

### 그로스
- 3층 도달 구조: ① 이메일 52명(실읽음 15~21, 재방문 불요 유일 채널) ② 푸시 5→13~19명 회복
  (재동의카드 +5~8, 신규가입 첫밥 옵트인 +3~6) ③ 인앱 3종(팝업·홈 프리뷰·커뮤니티 공지) 40~70명.
- 합집합 상한 = **가입자 35~50명(9~13%)**. 나머지 ~300명은 동의도 재방문도 없어 어떤 수단으로도 불가.
- "오픈을 알게 되는 사람" 절대수 1위는 인스타(700~800 방문/2주) — 단 D-day 전 소재 교체 금지
  (지금 유도하면 "결제 준비 중" 데드엔드로 광고비 낭비).
- 시한부 액션: D-7 월요일 다이제스트에 티저 실기 — 놓치면 이메일 접점 2회→1회.
- 전체 쪽지를 "전원 발송 완료"로 보고하는 건 전형적 허수(도달 집합=어차피 앱 여는 사람) — 금지.

### 악마의변호인
- 강행 시 진짜 비용(순서대로): ① 자기 DB가 고의성 증거(동의 분리 기록·opt-in 코드·체크리스트에
  스스로 적어둔 (광고) 규정 → "몰랐다" 불가) ② Resend 계정·도메인 평판 — 이후 주문확인·배송
  메일이 스팸함 가는 쇼핑몰이 됨(복리 손실) ③ 개보법 목적외이용 + B2G·지원사업 심사 신뢰.
  엄살로 판정: 과태료 즉시 3천만(현실은 시정지도 가능성), 언론 스캔들(360명 규모론 확률 0).
- 역공격: 합법이라도 콜드 360명 기대 방문 ~7명·기대 구매 0건. **오픈 공지는 1회성 탄환** —
  죽은 청중에 소진하지 말고 청중 회복 후 실오픈 날 쏠 것.
- 숨은 가정 파괴: "360명은 청중이다"(→화석), "도달=방문"(무료 행동 전환도 6%),
  "방문=구매"(빈 깡통 상태 방문은 불신 적립), "트래픽=무조건 플러스"(원가는 신뢰).
- 시점 경고: 발송은 실오픈(라이브 결제+실상품+스모크 1건) 후에만 성립.

## 확정 실행안

1. **[코드 1건·핫픽스 성격] `/api/push/broadcast`에 마케팅 동의 필터** — 위법 발화 가능 구조의
   봉인. 화이트리스트 ③(보안/컴플라이언스) 해당 여부는 사장님 승인으로 확정.
2. **[무코드·지금] 티저 3종**: D-7 다이제스트 티저 + admin 접속 팝업 "오픈 예정·찜 해두기" +
   커뮤니티 고정 공지. 찜 유도는 결제 게이트(15명·40찜) 채우기와 이해 일치.
3. **[무코드·계속] 푸시 교집합 격일 프로브** (기준선 8/12 = 5명, 목표 D-day 13~19명).
4. **[D-day] 4채널 동시**: 이메일 단발(광고 표기) + 동의자 푸시(저녁, 21시 전) + 팝업 본공지 +
   인스타 소재/랜딩 교체.
5. **[봉인] 무동의 이메일 블라스트·전 구독자 즉시발송** — 제안 자체 금지.
