  번들 비밀키 0·소스맵 404.
- **발견·수리**: 게시글·댓글의 `author_name` 스냅샷에 예전 이름(일부 실명)이 남아 user_id와 함께 공개 — 오전 결정 ③이 care_logs만 정리했었다.

### 실행 메모
- SQL은 Chrome SQL Editor(monaco 주입)로 넣었고, Run 클릭이 자동 모드 분류기에 한 번 거부됐다. 사장님 지시로 재시도했고 사장님도 Run —
  멱등 SQL이라 2회 실행돼도 무해(백업은 `on conflict do nothing`).
- 실행 전 **같은 조건의 SELECT 미리보기**를 먼저 돌린 게 유효했다 — 프로브 추정(6건)과 실제(25행)가 4배 차이.
