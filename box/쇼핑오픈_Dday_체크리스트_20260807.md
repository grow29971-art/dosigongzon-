## 상품 활성화 전 반드시 고칠 문구 (도메인 검토)

- **이동장** — 현재 "TNR 이동, 병원 이동 시 필수". **TNR 포획은 통덫으로 한다.** 이동장으로 포획을 시도하면 탈출·부상·물림 사고가 나며, 초보 캣맘의 전형적 실수다. "병원 이동용"으로만 표기할 것
- **츄르** — 현재 "경계심 있는 아이들도 다가옵니다". 손에서 받아먹도록 길들인 개체는 **학대에 취약해진다**(커뮤니티 합의 원칙). "손으로 직접 주지 마세요 · 급여 후 포장재 회수" 문구로 교체
- **야외 쉼터하우스** — 무단 설치는 관리규약 위반·철거·캣맘 신상 노출로 이어진다. 설치 전 확인사항(공용부 관리주체 동의, 소방통로·주차장 금지, 관할 구청 조례 확인, 설치자 연락처 표기, 철거 요청 시 이동)을 상품에 명시
- **영양제(유산균·타우린)** — 공동 급식소는 개체별 급여량 통제가 불가능해 개념이 성립하지 않는다. "개체 관리가 가능한 경우(임보·구조·단독 관리묘)에만" 한정 표기. *수의사 검토 필요*
- **급식그릇** — 사료 방치가 민원 1순위. "정시 급여 후 회수, 잔반·포장재 정리" 문구 필수
- **구조 결함**: `products`에 주의사항 전용 컬럼이 없어 안전 문구가 `description`에 섞이는데, 상세 화면은 5줄을 넘으면 접힌다(`ProductDetailClient.tsx:53`) → **경고가 접힘 안에 숨는다.** `caution` 컬럼 추가 + 항상 펼쳐지는 경고 블록 필요

## 상품 구성 판정 (사업 검토, 시장가 실측 대조)

**18종 중 확실한 흑자는 에코백 1종뿐이다.** 나머지는 마진이 얇은 게 아니라 **그 가격에 매입할 도매처가 없다.**

- 츄르 60개입 18,900원 — 시장 소매 30,180~31,900원 (**소매가의 59%**)
- 오리젠 1.8kg 38,000원 — 시장 39,900~42,000원 (소매가보다 쌈)
- 쿠팡 로켓과 정면 경쟁 15종. 가격·배송·신뢰 어느 축도 이기지 못함
- 배송비가 상품가의 30%를 넘는 것 7종(낚시대 67%, 스티커팩 51%)
- 18종 중 **9종이 실내 반려묘 전용**(모래·스크래쳐·캣닢쿠션 등) — 길고양이 앱 정체성과 불일치

**최소 오픈 구성 권고**: 에코백 15,000 + 키링 10,000(8,000에서 인상) + 번들 22,000. POD라 재고·현금·미발송 리스크 0.
목표는 매출이 아니라 **운영 사이클 1회 완주**와 실측 데이터 확보.
