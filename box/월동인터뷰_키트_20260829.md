# 월동 인터뷰 키트 + 9/2 판정 기준 박제 (2026-08-29 원탁회의)

## 0. 지속 가능 설계 (악마의 변호인 처방 — 번아웃 재발 방지)
- **목표 하향: 10명 → 3명** (3명이면 충분한 신호. 건강한 주의 분량)
- **오전 1블록만** 발품/인터뷰. 오후엔 강제 없음
- **이번 주 번복 0회** — 되돌릴 수 없는 결정은 48시간 묵힌 뒤 실행
- 거절은 데이터다: "거절 N회"도 면담록에 기록(시장 반응의 일부)

## 1. 어디서 만나나 (도메인 판정, 성사율 순)
1. **오프라인 급식소 대면** (산책 겸, 기대 1~2명) — 최선
2. **기존 케어기록 유저 DM** (기대 1~2명)
3. **당근 동네생활 글 1건** (기대 1~2명 + 당근 유입 채널 테스트 겸) — 아래 문구
4. 네이버 카페는 운영진 허락 없이 금지

## 2. 접근 문구 (심리 설계 — "같은 처지" 먼저, 개발자는 나중에)
- **당근 글/댓글**: "저도 ○○동에서 밥자리 하나 챙기고 있어요. 겨울집 준비 어떻게 하시는지 여쭤보고 싶은데, 편하실 때 댓글 주세요."
- **현장 대면**: "애들 밥 주시는 거죠? 저도 근처에서 돌보는 애가 있어서요, 월동 준비 얘기 잠깐 여쭤도 될까요?"
- 신분은 대화 열린 뒤: "실은 길고양이 앱 만드는 사람이기도 해요."
- ⛔ **절대 금지**: 급식소 위치·사진을 먼저 묻기 (신상 노출 공포 — 즉시 차단됨)

## 3. 질문지 (BM×도메인 — 과거 행동만 신뢰, Mom Test)
1. "작년 겨울집, 몇 개 만들었고 뭐가 제일 힘들었어요?"
2. **"지난번 사료 언제, 어디서, 얼마에 사셨어요?"** (kg당 가격 역산 — 대즐 4,667원/kg의 시장 대비 위치가 BM의 전부)
3. "월동 비축은 언제 시작하세요? 한 번에 얼마치?" (오픈 타이밍 리스크 — 비축 피크 놓치면 3명 있어도 매출 0)
4. "같은 사료가 쿠팡에서 6만원이면 어디서 사시겠어요?" (TNR 10% 프리미엄 트레이드오프 — "후원 좋아요"는 무시)
5. "급식 기록은 어떻게 남기세요? 안 남기면 왜?" (앱 코어 가설)
6. "작년 겨울 제일 아쉬웠던 거, 그거 해결되면 얼마까지 쓰실 것 같아요?"

## 4. 구매의사 판정선 (BM)
| 신호 | 판정 |
|---|---|
| "좋네요 사볼게요" | ❌ 불인정 (예의상 긍정) |
| 가격·배송·시기를 본인이 먼저 캐물음 | 약한 인정 |
| **"오픈하면 문자 주세요" + 연락처 + 시기 특정** | ✅ 인정 (생존조건 "3명"의 기준선) |
| 예약금 이체 의사 | 골드 (단 ⚠ 실입금은 받지 말 것 — 결제 오픈 전 규제 플래그) |

## 6. 🔒 9/2 판정 기준 — 오늘 박제, 당일 재해석 금지 (악마 생존조건 ③)
- **첫밥 fallback**: 8/26 이후 코호트에서 ①fallback 노출 유저 > 0 AND ②first_feed 주간 3건. **본인 계정·인터뷰 동행 유도분은 별도 표기하고 판정 본계산에서 제외.** 미달 시 무효 선언이 아니라 **9/9 연장** (표본 부족은 실패가 아님).
- **찜 게이트**: 기존 기준(유니크 15명·찜 40개) 재측정 — 미달이어도 결제 오픈은 토스 승인 기준으로 진행(8/26 회의 계승), 찜은 참고 지표로 강등.
- **signup_source**: 첫 분포는 **읽기만** — 4주 베이스라인 전 채널 판단 금지.
- 판정일에 하는 일: 숫자 읽기 + 기록. **대형 결정 금지** (결정은 목요일 이후 48시간 룰 적용).
