# [VS Code Claude Code 지시] 학대방지 + 캣맘 보호 기능 구현

## 역할·전제
너는 도시공존(Next.js 16 App Router + Supabase, PWA→TWA(Bubblewrap) 패키징, Vercel 배포) 코드베이스에서 작업하는 풀스택 엔지니어다.
목표: **길고양이 학대방지**와 **돌봄자(캣맘/캣대디) 본인 안전 보호** 기능을, **법적 리스크가 0이 되는 범위 안에서만** 구현한다.

> ⚠️ 이 문서의 "절대 금지선"을 하나라도 어기는 설계는 코드를 짜지 말고, 왜 막히는지 먼저 보고하라. 애매하면 항상 더 보수적인 쪽을 택한다. "될 것 같다"가 아니라 "확실히 안전하다"만 구현한다.

---

## 🚨 절대 금지선 (LEGAL RED LINES — 타협 불가)

1. **위치정보(LBS) 미신고 상태다.** 유저의 GPS 실좌표를 **서버(API/DB/로그/애널리틱스)에 저장·중계하지 마라.** 위치는 오직 클라이언트에서 획득 → 외부(다이얼러/문자/OS 공유시트)로만 흘려보낸다. 서버가 좌표를 "보는" 순간 위법이다.
2. **피제보자(가해 의심자) 신원 컬럼을 스키마에 만들지 마라.** 이름·차량번호·인상착의·얼굴사진 전용 필드 금지. 없으면 유출·무고·명예훼손 소송의 대상 자체가 없다.
3. **플랫폼이 "학대" 여부를 판정하지 마라.** 신고 상태값은 `접수 → 이관 → 종결`만. `학대확정`, `guilty`, `abuser` 같은 판정 상태·플래그·블랙리스트·공개등급 절대 금지. 도시공존은 **심판자가 아니라 라우터(통로)**다.
4. **"안전을 보장한다"는 표현·기능 금지.** "자동신고", "SOS 시스템이 지켜드립니다", "긴급 출동" 류 카피 전면 금지. 앱은 "휴대폰 기본 기능(전화/문자)으로 연결해주는 바로가기"일 뿐이라고 정직하게 표기한다.
5. **실시간 위치추적/상시 위치공유 기능은 구현하지 마라.** (LBS 신고 대상 + 스토킹 악용 + TWA 기술 불가). 이번 스코프에서 완전 제외.
6. **112 자동발신 금지.** 반드시 사람이 확인(2탭) 후 OS 다이얼러가 발신. 오발신은 무고·업무방해.
7. **프로덕션 DB에 직접 쓰지 마라.** 마이그레이션은 `.sql` 파일로만 준비하고, 실행은 사람이 Supabase SQL Editor에서 한다. 배포 순서·검증 절차를 문서로 남겨라.

## 구현 스코프 (이것만, 이 순서로)

### A. 캣맘 보호 — "곁에 있어요" (최우선, 법적으로 가장 깨끗)

**A-1. 112 빠른 전화 버튼** (반나절)
- 지도 화면에 상시 노출. `tel:112` 딥링크로 **OS 다이얼러를 여는 것**뿐(자동발신 아님).
- UX: 1탭 버튼 → 2탭 확인창("112에 전화를 겁니다 [전화][취소]") + **현재 주소/좌표를 화면에 크게 표시**(유저가 통화 중 불러줄 수 있게). 좌표는 화면 표시용이며 **서버로 전송 안 함**.
- 별도로 `tel:119`(응급의료) 옵션도.
- 카피: "112 전화 걸기"(O) / "긴급신고 시스템"(X). 최초 1회 한계 고지: "이 기능은 휴대폰 전화 앱을 대신 열어줍니다. 통신 상태에 따라 실패할 수 있습니다."

**A-2. 내 위치 보내기 (서버 무경유)** (1일)
- 버튼 → `navigator.geolocation.getCurrentPosition()` 1회 → `https://maps.google.com/?q=lat,lng` 링크 생성 → `navigator.share()`(Web Share API) 또는 `sms:` 로 **유저가 지정한 수신자에게 직접** 전송.
- **좌표가 우리 서버·DB·로그·애널리틱스에 단 1바이트도 닿지 않게.** 애널리틱스 이벤트는 `sos_triggered` 같은 무좌표 카운트만.
- 보호자 연락처(이름 별칭 + 전화번호만)는 **기기 로컬(localStorage/IndexedDB)에만** 저장. 서버 저장 금지.
- 위치 획득 실패 시 침묵 실패 금지 → "위치 확인 실패" 즉시 표기.
- `"use client"` 컴포넌트로 분리(RSC 아님).

**A-3. 안심귀가 체크인 (선택·2차)** — 착수 전 사람에게 확인받고 진행
- "N분 후 도착 체크인" → 미응답 시 지정 보호자에게 알림. **알림 본문에 위치 미포함**("OO님이 체크인에 응답하지 않았어요"만). 위치 넣으면 서버 저장 발생 → 금지.
- 만료 전 넉넉한 취소/스누즈 창 필수(오알람 방지).
- "우리가 지킨다"는 약속 톤 금지. "동료끼리 서로 챙기는 끈"으로 카피.

**심리/카피 원칙(A 전체 공통):** 기능명은 공포 프레임(SOS/긴급/신고) 대신 안심 프레임("곁에 있어요"). 빨간색·위협 표현 최소화. 위급 트리거는 색·위치·길게누르기로 학습부담 0.

### B. 학대방지 — QR 익명 목격제보 라우터 (공수 거의 0, 법적으로 안전)

**B-1. QR 지킴판 랜딩 + 익명 제보** (며칠)
- 인쇄 QR에 **쉼터/구역 ID를 인코딩**. 스캔 → 딥링크 랜딩("이곳은 등록된 돌봄 구역입니다. 위해행위는 동물보호법 위반입니다") + 원클릭 익명 제보 폼.
- **제보자 GPS를 받지 않는다.** 위치는 QR에 심긴 고정 구역 ID로만 태깅 → LBS 제약 우회.
- 제보 폼은 **구조화 필드만**(발생유형 enum, 대략 시각, 대상 동물 상태). 자유서술은 사법 이관용으로 분리 저장하되 평문 노출 금지.
- Supabase 테이블: anon insert 허용 + RLS + rate limit/captcha(스팸·무고 방지). 제보자 본인도 타인 제보 조회 불가(RLS).
- ⚠️ QR을 실제 밥자리에 직접 붙이지 않는다(위치 광고 역효과) — 동네 진입부·게시판 레벨. UI/문서에 이 원칙 명시.

**B-2. 증거 첨부 신고 → 기관 이관 헬퍼** (반나절~1일)
- 기존 `reports` 파이프라인에 **사진 1~3장 첨부**. 업로드 즉시 **서버에서 EXIF strip**(GPS·기기ID 제거) — 단, "관할기관 제출용 증거팩"을 유저가 명시적으로 생성하는 경우에만 원본 EXIF를 그 패킷 안에 보존(동의 기반, 포함 항목을 유저에게 표시).
- 신고는 도시공존이 판정하지 않고 **경찰/동물보호센터로 넘기는 서식 정리 헬퍼**로만. "법적 효력"·"수사자료" 주장 금지 → "신고 양식 정리 + 원본 무결성 해시(SHA-256)"로 정직하게.
- 모든 증거 행에 **`purge_at` 파기 타이머** 컬럼 강제. cron이 스토리지 객체 + 행을 hard delete. 이관 후 파기.
- 사진은 **비공개 버킷 + 단수명 서명 URL**. public 버킷 금지.

## 작업 방식 (반드시 이 절차로)

1. **먼저 조사·보고**: 착수 전, 아래를 grep/read로 확인하고 요약 보고하라 — 기존 `reports` 스키마(피제보 식별 컬럼·좌표 컬럼·판정 상태값이 이미 있는지), 사진 업로드 파이프라인(`convertImageToWebp`/`isSafeImageUrl` 등), 지도 컴포넌트 위치, cron/Edge Function 구조, RLS 패턴. 기존 자산 재활용을 우선한다.
2. **계획 제시**: 조사 결과 기반으로 A-1 → A-2 → B-1 → B-2 순서의 구현 계획을 파일 단위로 제시하고 **사람 승인 후** 착수.
3. **커밋 단위로 작게**: 기능 하나 = 커밋 하나. 각 커밋 후 `tsc --noEmit` + `eslint` 통과 확인.
4. **마이그레이션은 파일로만**: `box/`에 `.sql` + 실행순서·검증 문서. 프로덕션 DB 쓰기 금지.
5. **자가 검증 체크리스트**(매 기능마다 확인하고 보고):
   - [ ] 유저 GPS 좌표가 서버/DB/로그/애널리틱스에 저장되는 경로가 하나도 없는가?
   - [ ] 피제보자 신원 컬럼이 스키마에 없는가?
   - [ ] 판정 상태값/블랙리스트/공개등급이 없는가?
   - [ ] "안전 보장/자동신고" 류 카피가 없는가?
   - [ ] 112는 사람 확인 2탭이고 자동발신이 아닌가?
   - [ ] 증거/제보 데이터에 `purge_at` 파기 타이머가 있는가?
   - [ ] anon 키로 민감 테이블 접근 시 401/0건인가(RLS)?
6. **모르면 멈춰라**: 법적으로 애매한 지점(예: 위치 저장 여부, EXIF 처리)은 코드 짜지 말고 질문으로 올려라.
