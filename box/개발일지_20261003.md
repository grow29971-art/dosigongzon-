  Apple 로그인 브리지 출처 미검증(eb883643).

## 2. 쇼핑 감사 — 악용(돈·재고·포인트) + 터트리기(마비·주입)

- 코드: confirm에서 `shipping_fee`·`total_amount`도 서버 계산값과 대조(7f92c11c) — 배송비 1원 주문으로 반품비를 피하던 경로.
  회원·라이브 게스트 RPC(9/17 합포장 버전)가 confirm과 같은 식이라 정상 주문은 영향 없음을 대조로 확인.
  키링 CSV 수식 주입 차단(ff741ef9).
- SQL `supabase_order_server_columns_guard_20261003.sql`: 브라우저 직접 INSERT 시 `delivered_at`·`refund_*`·`refunded_quantity`를
  초기화(반품 기한 무력화·재고 영구 품절). `current_user in (authenticated, anon)`일 때만이라 서버·게스트 RPC 경로 무변화.
  컬럼 누락 대비로 `jsonb_populate_record` 패턴.
- SQL `supabase_shop_dos_limits_20261003.sql`: **결제가 꺼진 지금도** anon이 `create_guest_order`에 품목 수천 개를 넣어
  order_items를 무한히 키울 수 있었다(게이트가 클라이언트에만 있음). 주문당 품목 20·수량 99·회원 시간당 30건.
- 롤백 전용 DO 블록 실측(authenticated 역할 흉내, 마지막 raise로 전부 되돌림): delivered_at 2099→NULL, refund_amount 999→0,
  refunded_quantity 1→0, 품목 21번째 차단.
- 결정 대기: 상품당 주문 수량 상한(즉시환불 반복 품절 유도), 비회원 전역 속도제한 구조(그 자체가 DoS). D-day 게이트 추가: 대사 크론 50건 창,
  정리 크론 실패 시 적립 결행, 관리자 주문 목록 200건, 실패 페이지 `?message=` 위조.
