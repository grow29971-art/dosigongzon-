## TASK 2 — Kakao Maps 앰비언트 타입 선언 추가 (no-explicit-any 15→3, 저비용 고효과)

**목적:** `app/(main)/map/page.tsx`의 `no-explicit-any` 12건은 Kakao SDK가 타입을 안 줘서 생긴 구조적 any다. 전면 리팩터 없이 얇은 `.d.ts` 하나로 대부분 제거하고 SDK 오용도 타입으로 잡는다.

**지시:**
1. 먼저 `app/(main)/map/page.tsx`에서 `window.kakao` / `any`로 접근하는 Kakao 객체·메서드를 **실제 쓰는 것만** grep으로 목록화하라 (예: `kakao.maps.Map`, `Marker`, `LatLng`, `services.Geocoder`, `event.addListener` 등).
2. `types/kakao-maps.d.ts`를 새로 만들어 **실제 쓰는 메서드/속성만** 얇게 선언하라. 전체 SDK를 다 선언하지 마라(과설계 금지).
3. `map/page.tsx`의 해당 `any`를 새 타입으로 교체하라. **동작은 절대 바꾸지 마라** — 타입만 붙인다.
4. `tsconfig.json`의 `include`에 `types/**/*.d.ts`가 포함되는지 확인(대개 자동 포함).

**주의:** 남는 any(2~3건)가 있으면 `// eslint-disable-next-line @typescript-eslint/no-explicit-any` + 사유 주석으로 명시적 예외 처리.

**검증:** `npx tsc --noEmit` 에러 0, `npx eslint "app/(main)/map/page.tsx"`에서 no-explicit-any 대폭 감소 확인.

## TASK 3 — lint 순수 정리 (87 error → 실질 0, 신호 대 잡음 개선)

**목적:** 진짜 위험(무한 렌더 루프 등)이 노이즈 87개에 묻히지 않게 한다.

**지시 (순서대로, 각 소분류마다 검증):**
1. `no-unused-vars` 30건: 미사용 import/변수 제거. **단, 실제 사이드이펙트 import(예: `import "server-only"`)는 지우지 마라.**
2. `prefer-const` 1건 (`lib/news-crawler.ts:156`): `let`→`const`.
3. `@next/next/no-html-link-for-pages` 1건 (`app/terms/page.tsx:175`): 내부 링크 `<a href="/shop/policy/">`를 `next/link`의 `<Link>`로 교체 (실제 UX/성능 개선).
4. `react-hooks/set-state-in-effect` 28건: **자동 수정 금지.** 각 위치를 확인해 "마운트 1회 세팅"이면 `// eslint-disable-next-line react-hooks/set-state-in-effect // mount-only, 사유` 로 의도 명시. 만약 렌더마다 setState 하는 진짜 루프가 있으면 그것만 별도 커밋으로 수정하고 개발일지에 기록.

**검증:** `npx eslint .` error 수가 크게 줄었는지 확인. 남긴 disable은 전부 사유 주석 포함.
