# [VS Code Claude Code 지시] 언론 노출 前 방어 하드닝

## 배경
도시공존(Next.js 16 App Router + Supabase, Vercel, PWA→TWA, 1인 창업자)이 곧 언론 노출(집회·단독인터뷰·매거진)로 주목받는다. 노출 직후 안티·경쟁자·혐오세력의 공격이 예상된다: 법적 신고(개인정보/위치정보/특허 허위표시), 기술 공격(스크래핑·과금폭탄·RLS 우회), 여론전. **노출 전에 "캡처 한 장이면 신고 성립"하는 구멍부터 닫는다.**

> ⚠️ 이 문서는 **P0(노출 전 필수)** 항목의 코드·문서 작업 지시다. 프로덕션 DB에 직접 쓰지 마라(마이그레이션은 `.sql` 파일로만, 실행은 사람이 Supabase SQL Editor에서). 새 기능 배포가 아니라 **방어 하드닝**이므로, 기존 동작을 깨지 않는 것을 최우선으로 한다. 애매하면 멈추고 보고하라.

## 작업 순서

### STEP 0 — 먼저 조사·보고 (코드 안 고치고)
아래를 grep/read로 확인하고 **요약 보고부터** 하라. 보고 받고 승인 후 STEP 1 착수.

1. **유저 GPS 실좌표가 서버로 가는 경로가 있는가?**
   - `navigator.geolocation` / `getCurrentPosition` / `watchPosition` 사용처를 전부 찾고, 그 좌표가 `fetch`/`insert`/`upsert`/Supabase로 전송·저장되는 라인이 하나라도 있는지. (위치정보법 미신고 상태 → 서버 저장 시 형사 리스크)
   - 급식소/고양이 좌표가 등록 시 오프셋(퍼징)되어 저장되는지, 실좌표 컬럼이 REST/API로 노출되는지.
2. **profiles 테이블 RLS 상태** — SELECT 정책이 `USING(true)`인지, authenticated가 남의 `invite_code`/`coins`/`email`을 조회 가능한지. `box/` 아래 대기 중인 락다운 SQL(`supabase_profiles_authenticated_lockdown_migration.sql` 등)과 RUN_ORDER 문서 확인.
3. **"특허" 문구** — 앱/웹/랜딩/about/매거진 초안 등 전 코드·문서에서 "특허"가 "출원 중" 없이 단정적으로 쓰인 곳 전부 grep.
4. **이미지 업로드 파이프라인** — EXIF(특히 GPS) strip이 되는지, MIME 화이트리스트·용량 상한이 서버측에 있는지. (`convertImageToWebp`, `isSafeImageUrl` 등 기존 유틸 확인)
5. **개인정보처리방침·이용약관 파일** 위치와 현재 포함 항목.
6. **service_role 키·AI 키**가 클라이언트 번들/로그/에러응답에 노출되는지 grep.

→ 위 6개 결과를 표로 요약 보고. "이미 안전한 것 / 지금 막을 것"을 구분해서.

### STEP 1 — 특허 허위표시 제거 (반나절, 즉시·형사리스크)
- 전 채널 "특허" → **"특허 출원 중(출원번호 10-XXXX-XXXXXXX)"**로 통일. 앱·웹·about·랜딩·매거진 초안까지. (출원번호는 사람에게 물어서 채운다)

### STEP 2 — GPS 서버전송 차단 확인·수정 (형사리스크)
- STEP 0-1에서 유저 GPS가 서버로 가는 경로가 발견되면 **그 경로를 차단**(클라이언트 내 지도 표시용으로만, 서버 미전송). 급식소 좌표 오프셋이 서버측에서 적용되는지 확인, 실좌표 API 노출 시 차단.

### STEP 3 — 이미지 EXIF strip + 업로드 하드닝
- 업로드 시 **서버측에서 EXIF(GPS 포함) strip**. 기존 저장 이미지도 소급 제거 스크립트(`.ts`) 준비(실행은 사람이).
- MIME 화이트리스트(image/jpeg,png,webp) + 매직바이트 검증 + 용량 상한 서버측 강제.

### STEP 4 — profiles RLS 락다운 검증 준비 (마이그레이션은 파일로만)
- 대기 중인 락다운 SQL과 앱 코드 repoint 상태를 점검. 배포 순서·anon키 재검증 절차를 문서로 확정(`box/`). **프로덕션 실행은 사람이.** 코드가 락다운 후에도 안 깨지는지(공개컬럼 뷰 경유) 확인.

### STEP 5 — API 남용 방어 (과금폭탄·폭주)
- 카드생성(generate-card)에 **플랫폼 전체 일일/시간당 총량 글로벌 서킷브레이커** 추가(기존 per-user rate limit 위에). 원자적 카운터(Supabase RPC `security definer` 또는 기존 rate-limit 유틸 재사용). 초과 시 한국어 "잠시 후 다시" 안내.
- 회원가입·로그인·신고/제보 폼에 **Cloudflare Turnstile**(Supabase Auth 네이티브 통합) 부착 준비. 신고/제보는 **유저당 일일 제출 상한**(DB 카운터).
- 목록/공개 API에 **서버측 `limit` 상한**(예: 50) + cursor 페이지네이션. `limit=99999` 무시. 비인증 응답의 좌표 정밀도 **격자 스냅(~100m)**으로 다운그레이드.

### STEP 6 — 신고/제보 기능 역이용 방어 (profiler 관점)
- 제보에 **타인 신상(얼굴·차량번호·이름)이 담기면 자동 마스킹/차단** — 안 그러면 우리가 개인정보보호법 위반 주체가 된다.
- 모든 제보 원본 IP·타임스탬프 로그 보존(대표 무고 시 반증 증거). 단 `purge_at` 파기 타이머와 병행.
- 신규·저신뢰 계정 제보는 격리 큐. 판정 상태값(`학대확정` 등) 금지 — `접수→이관→종결`만.

### STEP 7 — 개인정보처리방침·이용약관 방어조항 (문서)
아래를 초안으로 작성/보완(법률 최종검토는 별도):
- 처리방침: **국외이전 고지**(Supabase·Vercel·Cloudflare 수탁국/업체/항목), 위탁업체 목록, 만14세 미만 제한, 보유기간·파기, 이용자 권리행사, 개인정보보호책임자·연락처, 침해신고(118) 안내.
- 약관: **"위치정보를 서버에 수집·저장하지 않으며 지도 표시는 단말 내 처리"** 명문화(LBS 신고 전 방어선), UGC 이용허락 조항, **크롤링·자동수집·역공학·타 회원정보 무단수집 금지**(침투 시도 자체를 약관위반화), 저작권 침해 게시중단 절차, 손해배상 제한·준거법·관할.

## 자가검증 체크리스트 (STEP별로 확인 보고)
- [ ] 유저 GPS가 서버/DB/로그에 저장되는 경로가 0인가?
- [ ] "특허" 단정 표기가 전 채널에서 사라졌는가?
- [ ] 업로드 이미지 EXIF GPS가 strip되는가(신규+기존)?
- [ ] profiles 락다운 후 앱이 안 깨지는가(공개컬럼 뷰)?
- [ ] 카드생성 글로벌 총량 상한이 있는가?
- [ ] 공개 API에 limit 상한 + 좌표 격자 스냅이 있는가?
- [ ] 제보에 타인 신상 자동 마스킹이 있는가?
- [ ] service_role/AI 키가 클라 번들·에러응답에 안 새는가?
- [ ] 처리방침에 국외이전·위탁·만14세·파기가 있는가?

각 STEP은 **커밋 하나**로. 매 커밋 후 `npx tsc --noEmit` + `eslint` 통과 확인.

## ⚠️ 이 문서 범위 밖 (사람이 대시보드/오프라인에서 직접 — VS코드는 못 함)
아래는 코드가 아니라 성우가 직접 해야 하는 것. VS코드는 손대지 말고, 완료 여부만 리마인드로 남겨라:
1. **Vercel Spend Management**(Pro 전환 + 상한 도달 시 자동 pause) / **Supabase Spend Cap ON** / **AI 제공자 월 예산 상한** — 파산 방어 90%.
2. **Cloudflare 도메인 앞단 프록시**(무료): Bot Fight + Rate Limit 룰 + Under Attack 토글.
3. **UptimeRobot → 텔레그램 알림**(정적 헬스체크 `/api/health`).
4. **후원 계좌 3분리**(개인/사업/집회) + 기부금품법(1,000만원 이상 모집) 등록 요건 확인.
5. **신상 분리**: 사업자·후원 계좌 주소를 자택 아닌 곳(공유오피스·사서함), 도메인 whois 대행.
6. **모니터링 방화벽**: 악플·신상위협을 대표가 직접 보지 않도록 신뢰할 1~2인이 필터링해 하루 1회 요약.

우선 **STEP 0(조사·보고)**부터 시작하라.
