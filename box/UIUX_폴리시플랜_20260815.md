## 1. 레퍼런스 방향 (핀터레스트/모빈 리서치 종합)

### 무드 한 줄
**"저채도 뉴트럴 위에 테라코타 딱 한 점"** — 8/13 브랜드 문서의 비주얼 방향과 동일. 레퍼런스들이 공통으로 말하는 것:

- **60/30/10 배분**: 배경·표면 60%(웜 화이트/화이트), 구조 요소 30%(그레이 스케일), 액센트 10%(테라코타). 액센트가 10%를 넘는 순간 촌스러워진다. 현재 앱은 액센트·강조가 인플레 상태(오딧 진단과 일치).
- **클레이 CTA + 오프화이트 표면 + 차콜 텍스트**: 테라코타 팔레트를 "따뜻하지만 정돈되게" 쓰는 정석 조합. 우리 토큰(#AD5E3B / #F9FAFB / #191F28)이 정확히 이 구조 — **토큰은 이미 답이고, 문제는 토큰 밖 하드코딩 510종**.
- **바텀시트 문법** (지도 = 첫인상 화면): 가로 전폭 + 화면 하단 스냅, 드래그 핸들바 명시, collapsed/half/full 3단. 시트가 지도와 "페어링"되는 논모달이 정석. 지금 고양이 시트의 2.5px 컬러 프레임 + 글로우는 이 문법 밖(포켓몬GO 톤) — P2에서 CatCard 격리와 함께 완화.
- **디테일 폴리시 정석**: 4/8pt 간격 그리드, radius는 4·8·16·24 계열 소수 정예, 중첩 라운드는 콘센트릭(바깥 radius − 패딩 = 안쪽 radius), resting 요소는 헤어라인 보더 + 미세 그림자, 떠 있는 요소만 레이어드 섀도.

### 유저가 직접 핀터레스트 볼 때 검색 키워드
`warm neutral mobile app ui` · `terracotta app ui` · `map bottom sheet ui` · `pet care app clean ui` · `toss style minimal` · Mobbin에서 `map` 스크린·`bottom sheet` 엘리먼트 탐색

## 3. 디테일 10칙 (신규 코드 즉시 적용, 기존 코드는 배치로 수렴)

1. **색**: 신규 hex 금지. 유채색은 primary/care/sage/error/warning/like 6개 + soft 틴트 5종만. 예외는 hex_토큰_매핑표 C절(지도 마커·카카오 브랜드·밤하늘·CatCard 인디고)만.
2. **그림자**: resting 카드 = `--color-border` 헤어라인 + `--shadow-card-sm`. 떠 있는 것(FAB·네비·시트·모달)만 raised 이상. **컬러 글로우 금지**(CatCard 격리 구역 예외). 신설 제안: `--shadow-fab`, `--shadow-sheet` 2종(가드레일상 확정은 사용자 승인 필요).
3. **radius**: 토큰 9종만(곡선 14/16/20/24/28/full + 사각 6/8/10). 사잇값 18→20, 22→20, 26→28, 12→10(사각) 스냅. 중첩은 콘센트릭.
4. **타이포**: 6단만, 소수점 px 금지. weight 400/600/700 3단 — extrabold(800)는 숫자 디스플레이 한정. 6단 정착 후 `body { zoom: 1.05 }` 제거(P0-2 순서 준수: 스냅 먼저, zoom 해제 나중).
5. **보더**: 외곽 `--color-border`, 내부 구분 `--color-divider`. rgba(0,0,0,.0x) 직접 표기 금지. primary 알파 파생 5종 → `--color-primary-soft` 계열로.
6. **간격**: 4/8 그리드. 페이지 컨테이너 `px-4 pt-14 pb-24`(현행 최다 조합 채택). 칩 패딩 `px-3 py-1.5` 단일.
7. **강조 예산**: 화면당 primary 채움 버튼 1개, 첫 스크린 프롬프트 1개(오딧 원칙), 그라디언트 0(잔여 306건 → 플랫), 시스템 이모지 0(→ lucide).
8. **프레스**: `.press`(scale 0.97) 단일. active:scale 인라인 8종 폐기.
9. **프리미티브 경유**: 새 UI는 ui/Button·Card·ListRow·SquareToggle + 신설 Chip·Sheet로만. 화면 인라인 재구현 금지.
10. **모션**: `--motion-*` 3단만. slide-up은 전역 유틸 1개.
