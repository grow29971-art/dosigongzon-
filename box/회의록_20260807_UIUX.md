## 0. 이 회의가 만든 판정 기준

UI를 만질지 말지를 취향으로 다투지 않기 위해 **2축**으로 갈랐다.

| 축1 — 기존 계측 발화 지점을 옮기는가 | 축2 — 도달 불가(0)를 여는가, 이미 도달 가능한 것의 설득력을 바꾸는가 | 판정 |
|---|---|---|
| No | **도달성** | 오늘 실행 |
| No | 설득력 | 8/18 이후 (231세션에선 검출 불가 = 해도 모름) |
| **Yes** | 무관 | 금지 (게이트 훼손) |
| — | 현재 0건 경로에 **신규** 발화 추가 | 계측 복구, 즉시 |

**결정적 실측**: `cat_detail_view_anon`은 `PickCatSignupCta` **마운트 시** 발화한다
(`PickCatSignupCta.tsx:20-22`, 뷰포트·스크롤 기준 아님). 따라서 **JSX 순서를 바꿔도
발화량은 변하지 않는다** — 악마의 "레이아웃 변경 = 계측 교락" 논거가 이 항목엔 성립하지 않는다.
그리고 8/9·8/11·8/18은 전부 **존재 검사(≥N)**이지 before/after 비율 비교가 아니다.
`cat_detail_view_anon`은 8/7에 생긴 스텝이라 baseline이 0행 — **없는 기준선은 오염될 수 없다.**

현재 기록된 `signup_home` 27건은 전부 pick을 안 거친 가입이다.

**2번**: 비로그인 최대 primary 버튼이 `/map?cat=`으로 보내는데 지도 시트의 돌봄 탭은

pick CTA보다 시각적으로 강해 pick 경로를 새게 만들고 있었다(pick=1의 물리적 원인).
※ 디자이너 원안(`/signup?next=`)은 **기각** — 그 경로는 `pending_care` 커밋과
`onboarding_pick` 발화를 안 거쳐 **계측 밖 두 번째 가입 경로**를 만든다.

배포 후 검증: 비로그인 상세 HTML에 "지도에서 돌봄하기" 0건, 가입 CTA 1건 확인.

## 4. 8/18 판정 문장 — 교체 확정

기존 "상세→첫밥 완주 2명"은 **분모가 없어 실패 원인을 못 가른다.** 아래로 대체한다.

> **8/18 23:59 기준, 8/7 개입 커밋 이후 발생분만 집계.**
> (a) `cat_detail_view_anon` ≥ 30건
> (b) `onboarding_pick` / `cat_detail_view_anon` ≥ 12%
> (c) `first_feed` 고유 유저 ≥ 2명

해석 규칙 (이게 핵심이다):

| 결과 | 의미 | 다음 액션 |
|---|---|---|
| (a) 미달 | **판정 보류.** 트래픽 부족이지 구조 실패가 아니다 | 유입 1채널 확보 |
| (a)○ (b)✕ | 상세가 가입을 못 만든다. 유입이 아니라 설득 문제 | **이때 비로소 카피 8쌍 해금** |
| (a)(b)○ (c)✕ | 가입 후 착지가 끊김 | `signup_home` 유무로 위치 특정 — 있으면 첫밥 바, 없으면 가입 완료 자체 실패 |
| 전부 ○ | 핵심 동선 생존 확정 | 유입 투자 개시 |

⚠ 8/18에 **"개입 덕분에 올랐다"고 말하지 않는다.** 대조군이 없다.
