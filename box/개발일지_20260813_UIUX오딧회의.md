## 1. 만장일치 합의 — "촌스러움"의 정체

**토대는 문제가 아니다.** globals.css 토큰(테라코타+그레이 10단, 토스 TDS급), Pretendard Variable, 타이포 6단, 그림자/radius 토큰 전부 이미 수준급. **문제는 토큰 위의 과잉과 무법**:

| 실측 지표 | 값 |
|---|---|
| 하드코딩 hex 고유 색상 | **666종** (총 3,553회 / 222파일) — 구 웜브라운·세이지 팔레트 잔존 |
| 인라인 style={{}} | 3,219회 / 218파일 (토큰 var() 경유는 1/3뿐) |
| 임의 폰트 크기 text-[N.Npx] | 3,321건 (9.5/10.5/12.5px 등 0.5px 파생 6종) + `body{zoom:1.05}` 핵 |
| extrabold(800) | 1,146건 — "전부 굵으면 아무것도 안 굵다" |
| linear-gradient | 393건 (칩·뱃지·진행바까지) |
| 시스템 UI 이모지 | 405건 (버튼 "시작하기 🐾" 등) |

| 공용 ui/Button·Card 채택률 | **0%** (만들어놓고 유령화) |
| 홈 "밥 기록" 진입점 | 4곳 중복, 푸시 옵트인 카드 2장 동시 렌더(결함) |

**진단 한 줄**: 리디자인이 필요한 게 아니라 **"기존 시스템으로의 강제 수렴 + 덜어내기"**가 필요하다. 색·폰트 교체 없이(테라코타 동결 유지) 해결 가능.

## 2. 핵심 반전 2개 (그로스·행동심리 실측)

1. **광고 클릭자는 홈을 안 본다.** LandingOnboardingGate가 첫 방문자를 `/map`으로 즉시 리다이렉트("지도가 곧 온보딩" 7/22 B안). 홈을 갈아엎어도 첫인상은 1픽셀도 안 바뀜. 진짜 첫인상 = /map + MapIntroSheet → cats/[id] 상세.
2. **행동설계는 이미 좋다.** FirstFeedBar는 교과서적(보존 대상) — 단 배경색이 구 갈색 #C47E5A(토큰 이탈). 리디자인 효과는 first_feed보다 **푸시 수락률·Day1 재방문**이 먼저 움직인다(판정 지표 주의).
