## 1. 앱인토스 — 반려 사유 하나를 세 번 추격 (-4 → -7)

### 반려 1: "서비스 이용을 위한 외부 링크가 정상적으로 열리지 않아요" (00:32, -4)
상세 없음. 코드 훑어 원인 확정: 앱인토스 WebView는 외부 오리진 이동을 막는데 **next/link shim만 `Device.openURL`을 쓰고
본 앱의 평범한 `<a href="https://…">`·`target=_blank`·`window.open`은 방치**돼 있었다(보호지침의 지자체 링크, `tel:` 전화 등).
→ 문서 클릭 캡처 + `window.open` 패치로 전부 SDK로 돌리는 전역 브릿지 한 파일(5a1c78d7, `src/lib/external-links.ts`). 번들 -5.

### 실기기 증상 2종 (사장님 보고)
- "구청 연락처·병원 찾기 안 열림" → 둘 다 `tel:` 링크. 위 브릿지 적용 대상.
- **"페이지가 열렸다 안 열렸다, 마이 탭 무반응"** — PC(Playwright)에서 재현 불가. 탭 7회 왕복·히트테스트·에러 수집 모두 정상.
  가설: 토스 정적 호스팅이 `/mypage` 같은 **중첩 경로 직접 로드**(앱 복귀·새로고침·본 앱 코드의 `location.href` 대입)를 못 받는다.
  → **HashRouter 전환** + 에러 바운더리·화면 하단 에러 토스트(5670b763, 실기기 로그 수단이 없어서). 번들 -6 → 사장님 "다 잘됨".

### 반려 2: 같은 사유 (08:56, -6). 검토 요청 10분 만 = 자동 검사로 추정
심사자 채널톡은 "해당 앱 입점 가능"이라 답했는데 번들 파이프라인은 같은 문구로 반려. 어떤 링크인지 알 수 없어 **예방적으로 외부
이동 자체를 줄였다**(be88ec62): 약관·처리방침을 로그인 전에도 **앱 안 라우트**(`/#/terms`·`/#/privacy`)로, `dosigongzon.com`으로
가는 링크는 전부 앱 안 해시 라우트로. 체크리스트의 "자사 서비스 이동 유도 금지"에도 맞는 방향. 남은 외부 이동은 지자체 전화·
네이버 카페뿐. 번들 **20260922-7** 등록·검토 요청(12:47), 채널톡에 "어떤 화면의 어떤 링크인지(자동 검사면 기준)" 질의.

### 오늘 배운 것
- 심사 반려 문구가 한 줄뿐일 때는 **그 규칙이 커버하는 표면을 통째로 줄이는 게 빠르다**. 어떤 링크인지 찾는 것보다 "외부 이동을
  안 하는 구조"로 바꾸는 편이 재반려 확률이 낮다.
- 미니앱에 **BrowserRouter 금지**. 정적 호스팅에서 중첩 경로 직접 로드가 보장되지 않는다 → HashRouter. `city-toss/AGENTS.md`에 규칙화.
- 실기기 디버깅 수단이 없으면 **화면이 로그다** — 에러 토스트·에러 바운더리를 넣으면 사장님 스크린샷이 곧 스택트레이스.

## 오늘 배운 것

- **자동 심사에는 "이유를 묻기"와 "표면 줄이기"를 병행**한다. 답을 기다리는 동안 규칙이 닿는 면적을 먼저 줄이면 사이클이 짧아진다.
- **AI 티의 실체는 대부분 카피와 배치**다. 색·폰트·토큰은 세 번째 감사에서 이미 통과했는데도 느낌표·반짝이·설명 모달·CTA 중복이
  남아 있었다. 다음 감사 때도 시각 토큰보다 문장과 버튼 개수를 먼저 본다.
- **디자인 스킬의 자동 추천은 믿지 않는다.** 체크리스트(무엇을 하지 마라)는 유용하고, 생성물(이 색·이 폰트를 써라)은 평균값이다.
- 커뮤니티 봇은 **읽히지도 않는다**(글당 조회 1 미만, 유저 댓글 0). 봇 글 수를 늘리는 방향은 근거가 없다.
