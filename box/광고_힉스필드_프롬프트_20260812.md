# 도시공존 릴스 광고 — 힉스필드 프롬프트 패키지 v1 (2026-08-12)

**컨셉**: "이미 이름이 있었어요" — 매일 지나치던 골목 고양이에게 이름이 있고,
동네가 이미 함께 돌보고 있었다는 발견. 죄책감 마케팅 금지, 발견과 연결의 기쁨 프레임.
**형식**: 인스타 릴스 9:16, 총 ~20초, 6컷 (AI 클립 5개 + 앱 화면 녹화 1개).

## ⚠ 제작 규칙 3가지 (전 컷 공통)

1. **영상 안에 글자 금지** — AI는 한글(영어도)을 깨뜨린다. 모든 프롬프트에 no text 지시
   포함됨. 배경 간판·현수막도 차단. **한글 자막은 전부 CapCut에서 후편집으로 얹는다.**
2. **컷 3(앱 화면)은 힉스필드로 만들지 말 것** — AI가 UI를 그리면 한글이 깨진다.
   실제 폰에서 도시공존 지도 화면을 **화면 녹화**해서 그대로 쓴다 (제일 깨끗하고 진짜다).
3. **사람 얼굴·손 급여 장면 금지** — 얼굴은 AI 왜곡 위험 + 손 급여는 학대 방지 원칙 위반.
   사람은 뒷모습만, 급여는 "놓여 있는 그릇"으로만 표현.

## 생성 팁 (촬영감독·편집 회의 반영)

- **카메라 무브는 컷당 1개만** — 프리셋(Dolly In 등)을 앱에서 선택하고, 프롬프트에도 같은 무브를 글로 반복하면 재현율이 최고. 무브 2개 겹치면 워핑 급증
- **클립은 필요 길이의 1.5~2배로 넉넉히 생성** — AI 클립은 맨 앞뒤 0.2~0.5초가 뭉개지므로 편집에서 트림할 여유 확보
- 컷마다 3~4번 생성해서 제일 자연스러운 것 선택 (걷는 장면·두 마리 상호작용이 제일 위험 — 컷 4·6은 여러 번 뽑을 것)
- 왜곡 구간은 50% 슬로모(부분 적용) / 105~115% 줌인(가장자리 흐물거림 잘라내기) / 잘 나온 프레임 0.3초 프리즈로 감추기
- 전 클립에 CapCut에서 동일한 따뜻한 톤 필터 일괄 적용 → 클립 간 이질감이 "다른 신"처럼 느껴짐
- 이미지→영상(I2V) 모드를 쓸 경우: 첫 프레임 이미지를 먼저 만들고 모션만 지정하면 톤 일관성↑. 시드 이미지는 자체 촬영 or CC0만 (타인 사진·정부 제공 사진 금지)
- 자막 폰트는 **Pretendard**(앱과 동일, 상업용 무료) — 흰 글씨+검정 외곽선 2~3px, 테라코타(#AD5E3B)는 CTA·강조 단어에만
- 음악은 **메타 사운드 컬렉션**(광고 사용 명시 허용) 1순위 — 인스타 트렌드 음원은 광고 집행 시 제한 걸림
- 인스타 업로드 시 **AI 생성 라벨 체크** (메타 정책상 고지 대상)

## 집행 설계 (마케터 회의 확정안)

**타이밍 — 3단계**
1. 지금~8/17: 소재 제작·검수 + Ads Manager에 **일시중지 상태로 세팅만** (지출 0 = 측정 창 오염 없음)
2. 8/18~8/23: 계정 무행동 (8/24 판정의 전환 지연 관찰 기간 — 세트 추가도 금지)
3. 8/24 판정 **PASS 시에만** 게재 시작. 애매/FAIL이면 소재도 함께 보류 (채널이 죽는데 소재만 바꿔봐야 무의미)

**구조**: 광고세트를 3개로 쪼개지 말고 **단일 세트 + 소재 3개** — 월 10만원(일 3,300원)에서 3등분하면 통계 무의미, Meta 자동 최적화가 성과 좋은 소재에 지출을 몰아주게 한다.

**UTM**: `utm_source=ig_r2_a` / `ig_r2_b` / `ig_r2_c` (2차 릴스 라운드, 소재별). 기존 계측 코드가 이 포맷을 그대로 통과시킴 — 코드 변경 0. 소재↔토큰 매핑은 이 문서에 기록할 것.

**랜딩**: 기존과 동일한 온보딩 intro(루트). **/shop 금지** — 결제 라이브 전엔 콜드 트래픽을 쇼핑에 태우면 데드엔드 광고비. 찜 게이트는 웜 유저(팝업·이메일)로 채운다.

**판정 사다리** (first_feed는 이 예산에서 표본이 안 쌓이므로 선행지표부터 순차 컷):
- 1주: 소재당 클릭 30건 모이면 CPC 비교 → 1.5배 나쁜 소재 조기 탈락
- 2주: 소재당 가입 5건 기준 전환율 → 하위 1개 컷
- 3~4주: 남은 2개의 first_feed 절대 건수로 방향 판정
- 기준선(현 추세 환산): CPC ~183원 / 가입당 ~3,300원 / **first_feed당 ~50,000원**. PASS는 first_feed당 ≤25,000원, 애매하면 기존 독트린대로 중단 쪽.
- 판정 근거는 Meta 리포트가 아니라 **funnel_events의 source** (Pixel은 동의 후 마운트 + CAPI 미설정이라 유실 큼)
