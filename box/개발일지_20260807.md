## 4. 계측 — 이번 세션 최대 수확

### `cat_detail_view_anon` 신설 (8/9 하드 게이트)

`onboarding_pick`이 0으로 나와도 "동선이 안 닿았다"와 "닿았는데 안 눌렀다"를 구분할 수 없었다.
비로그인 상세 도달을 pick 앞단에서 재는 스텝을 신설.

**코드만 배포했을 때 조용히 실패했다** — `funnel_events.step` CHECK 제약이 새 스텝을 막아
`/api/funnel`이 500. 프로브로 잡아 CHECK 확장 SQL을 만들고 실행. 실제 삽입까지 확인.
검증 안 했으면 8/9에 "0건"을 보고 유저 문제로 오판했을 것.

### `signup_home` 구멍 봉합 (UI/UX 회의 발견)

**pick을 거쳐 가입한 사람은 홈이 아니라 `/cats/{id}`에 착지**해서 `PendingCareHandoff`가 뜨지 않고,
그래서 `signup_home`을 구조적으로 한 번도 찍을 수 없었다. 퍼널이 pick →(공백)→ first_feed로 끊김.
현재 기록된 27건은 전부 pick을 안 거친 가입이다. `FirstFeedBar`에 한 줄 추가로 봉합.

### 방문자 지표 수정

`/api/visit` GET이 `today`·`cumulative`·`total`을 구분해 반환하도록. 관리자 "오늘 방문자"가
수천에서 두 자릿수로 정상화. 라벨이 누적인 화면 3곳은 `cumulative`를 명시적으로 쓰게 함.

### 좋은 신호

`onboarding_pick`이 **전 기간 0 → 1건** 발화. 8/4 지도 클러스터 수리가 작동하기 시작했다.

## 5. 쇼핑 정리 (8/7)

- **투표 제거** — 표시 93표 중 80표가 시드값이라 대외 검증에서 깨지는 구조. 관련 문구 4곳 정리
- **중성화 마릿수** — 처음엔 `cats.neutered`(48마리)를 썼다가, "후원금으로 중성화한 아이"로
  의미를 바꿔 `fund_disbursements.neutered_count` 합계(현재 0마리)로 전환
- **기부율 10% → 5%** — 대주산업 공문에 5%로 명시했는데 DB는 10%였다. 공문 기준으로 통일.
  함께 "수익의 일부" → **"결제 금액의 5%"**로 표현 교체(수익=이익/매출 혼동은 표시광고법 소지)
- **정산 계산식 안내** — "자동으로 돌아가게 해달라"는 요청에 대한 답은 코드가 아니라 설명이었다.
  모인 금액은 이미 100% 자동(환불도 자동 차감), 수동인 칸은 "실제로 돈을 쓴 사건" 하나뿐
- **데드엔드 차단** — `SHOW_WEATHER_SHOP_BRIDGE=false`(홈에서 빈 쇼핑으로 보내던 마지막 링크),
  🚧 배너 "찜해두는 기간" → 찜할 상품이 0개라 실행 불가능한 지시였음

### 결제 오픈 시 터지는 폭탄 3개 — 일부러 안 고치고 박제

주문 0건이라 회귀 검증이 불가능해, 지금 고치면 미검증 결제 변경이 몇 주 방치된다.
`box/쇼핑오픈_Dday_체크리스트_20260807.md`에 위치·증상·수정 순서를 남겼다.

| 위치 | 증상 |
|---|---|
| `POINTS_MAX_USE_RATE = 0.3` | 상시 30% 할인. 유일 흑자 상품 이익 7,900 → 2,684원, 시간비용 빼면 +104원 |
| `shop-repo.ts:274` 배송비 `Math.max` | 20kg 사료 3개(60kg) 주문 시 배송비 0원, 실비 16,500원 손실 |
| `refund-policy.ts:21` 반품비 3,000원 고정 | 20kg 반품 왕복 실비 11,000원 → 건당 −8,000원. **`/shop/policy` 고지와 커플링돼 단독 수정 시 법 위반** |

### 사업 판정

시장가 실측 결과 **판매가가 소매가보다 싸다**(츄르 18,900 vs 시장 30,180). 이 가격에 떼올 도매처가 없다.
18종 중 확실한 흑자는 에코백 1종. 15종이 쿠팡 로켓과 정면 경쟁.
