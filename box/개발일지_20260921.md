## 1. 앱인토스 — 축소판(v1) → 본 앱 전 화면 포트(v2)

### 배경
v1(지도+돌봄 기록)로 QR 테스트가 통과한 직후 사장님이 "본래 웹앱이랑 똑같이 구성, 모든 기능 전부"를 지시. 선택지 제시 후
"되는 것 전부(규칙상 불가한 것만 제외)·전부 만들고 한 번에" 확정. 쇼핑은 토스페이 IAP 별도 계약 전엔 불가(결제 오픈 후 별도),
채팅·쪽지·서클은 "채팅 필수 사항" 미충족이라 제외 — 이유는 사장님에게 설명하고 합의.

## 오늘 배운 것

- **보안 헤더는 결제창의 적**: COOP same-origin은 카드사 인증 팝업을 죽인다. 토스 권고값 allow-popups로 두고 되돌리지 말 것.
- **Next 앱을 미니앱으로 옮기는 가장 짧은 길은 shim**: 화면을 다시 짜는 게 아니라 `next/*`와 Supabase 클라이언트를 바꿔 끼우면 된다.
  단 서버 페이지는 "함수 호출"로, react 버전은 고정으로, 서버 전용 모듈은 import 시 throw로.
- **심사자는 UGC 앱에서 "연락처 교환 경로"와 "의료 지시"를 본다**: 죽은 버튼(문의하기)과 DB 안의 투약 문구처럼 코드를 훑어야만
  보이는 것이 반려 사유가 된다. 채널톡으로 상세 설명하면 반나절 안에 풀린다.
- 심사 확인 사항은 코드로 실측한 뒤에 답한다 — "없다"고 답하려던 두 항목이 실측에서 구멍으로 드러났다.
