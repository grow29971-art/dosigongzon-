# 하드코딩 hex → 디자인 토큰 매핑표 (2026-08-13 UIUX 오딧 Phase 0)

> 실측: 고유 hex 666종 / 3,553회 / 222파일. 이 표는 상위 빈도 색의 귀속 판정.
> 원칙: **새 색 발명 금지** — globals.css의 기존 토큰으로만 수렴. 테라코타 동결(WAU 100까지) 준수.
> 치환은 파일군 단위 1커밋 + 스크린샷 비교 + 단독 revert 가능하게.

### 지도 마커 의미색 예외 목록 (2026-08-13 등록)

Phase 2 map/page.tsx 치환 작업(UI 크롬만 대상, 마커/오버레이 로직은 무변경) 중 발견한 보류 색 전체 목록.
치환 범위: `return (` 이전(줄 1~1996, Kakao CustomOverlay용 마커 생성 함수·SDK 호출부)은
전부 보류 — HTML 템플릿 리터럴 안의 색은 `var()`가 카카오맵 DOM에 그대로 문자열 주입되므로
안전이 검증되지 않음. 아래는 `return (` 이후(줄 1997~) JSX에서도 **의도적으로 남긴** 색.

| 하드코딩 | 위치(대략 줄) | 보류 사유 |
|---|---|---|
| `#AD5E3B` (고양이 필터 칩) | 2066 | "고양이" 레이어 칩 색 = 실제 고양이 마커 색과 동일값(범례 기능) |
| `#149D5B` (병원 필터 칩·accent) | 2067, 2836 | "병원" 칩·상세시트 accent = 병원 마커 그라디언트 c2와 동일값(범례) |
| `#F0762B` (약국 필터 칩·accent) | 2068, 2836 | "약국" 칩·상세시트 accent = 약국 마커 그라디언트 c2와 동일값(범례) |
| `#AD5E3B` / `#4A7BA8` (활동지역 슬롯1/슬롯2 탭) | 2204 | 지도 위 Circle 오버레이(줄 1141)와 동일 로직으로 페어링된 "범례" — 탭 색만 바꾸면 지도 원 색과 불일치 |
| `${accent}NN` / `${color}NN` / `${info.color}NN` 등 알파 접미사 결합 | 다수 | 리터럴 hex가 아니라 JS 변수 보간 — `var()`에는 알파 접미사(`40`, `66` 등)를 이어붙일 수 없어 대상 자체가 아님 |

보류하고 사실만 기록한다. 별도 확인·정리 필요.
