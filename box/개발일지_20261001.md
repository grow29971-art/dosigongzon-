## 3. 쇼핑 — 결제 오픈 전 감사 (3관점) 와 조치

- **치명**: `order_items_insert_own` RLS가 부모 주문 상태를 안 봐서 결제 끝난 주문에 상품 끼워넣기 → 발주 크론이 무료 발송.
  SQL(bcdddc87) 사장님 실행 → pg_policies with_check에 `status='pending' AND payment_key IS NULL` 확인. 게스트 취소 RPC도 결제키 조건 추가.
- 옛 `/api/payment/cancel`의 결제 후 즉시 전액환불 경로 제거(H-2 우회였음), 관리자 드롭다운의 "DB만 취소" 차단, 환불 시 구매 적립 회수 +
  등급 계산에서 취소·환불 제외, 결제키 없는 pending·취소 주문도 대사 크론이 토스 원장과 대조.
- **웹훅 서명**: 토스 공식 문서상 서명 헤더는 지급대행(payout·seller) 이벤트 전용 — 결제 웹훅에 시크릿을 넣었으면 전건 401이었을 것.
  검증 코드 제거·D-day 게이트 폐기(cc31c141). 위조 방어는 원래대로 토스 재조회.
- **비회원 환불 경로**: 주문번호 + 이 기기 게스트 토큰(URL에 싣지 않음)으로 셀프 환불(eba0347a), 기기 분실은 관리자 직권 환불(9271d509).
  환불 본체는 `lib/refund-request.ts`로 분리해 회원과 같은 규칙. security-guard 테스트에 인증 예외로 등록(대체 방어 패턴 명시).
- 법적 고지: 하자 3개월/30일 청약철회, 3영업일 환불·지연배상금 연 15%, 호스팅(Vercel)·결제대행·에스크로 미이용, 결제 화면 미성년자
  취소권, 약관 분쟁해결기준, 포인트 유효기간 없음·환불 시 적립 회수. 판매자 정보 블록은 카드사 심사 동결이라 손대지 않음.
- 후원금 사용처를 "길고양이 케어(중성화·쉼터 입소 등)"로 넓히고, **협약 완료 확인 후** "길냥이쉼터 묘연" 입소 지원 고지
  (심사로 결정·보장 아님, 구조 전 주인 확인 당부 포함).
