# 도메인 규칙

## 서비스 정체성과 수익 구조 (2026-09-02 사장님 확인)

- 앱 자체는 **무료·광고 없음**. 수익은 ① 쇼핑몰 판매(수익=이익의 10%를 고양이들에게 후원)
  ② 급식소·자판기 등 기관 상대 사업(B2G) ③ 정부 지원사업.
- 지금은 쇼핑 **결제 오픈 준비 단계**(토스 심사 대기). 결제가 꺼져 있어도 쇼핑 UI는 노출된다.
- 앱명은 **"도시공존"** 유지(2026-08-28 리네이밍 취소). "우리동네 길집사"는 앱명이 아니라
  **서클 기능의 이름**으로 쓴다. 법적 주체·도메인(dosigongzon.com)·상호는 도시공존.

## 사람·고양이 호칭

- 사람 호칭은 **"길집사"**로 통일. 예외 5종만 허용: AI 집사(챗봇), 감정 호칭, 이웃/시민 표현,
  SEO 키워드, `/caretakers` URL. **"캣맘" 단어는 새 문구에 쓰지 않는다**(혐오 프레임 표적어 +
  캣대디 배제).
- 죽은 고양이는 "고양이별로 갔다"로 표현하고 추모 모드로 전환한다(아래 참조).

## 고양이(cats)

- **공개 범위 3단계**: `public`(전체) / `circle`(내 서클 멤버만) / `private`(나만).
  등록 후에도 본인 핀에서 언제든 변경 가능해야 한다.
- 건강 상태 3단계: `good`(양호)/`caution`(주의)/`danger`(위험). 홈 스포트라이트는
  위험 → 주의 → 최근 등록 순으로 정렬한다.
- **추모(memorial_at)**: 값이 있으면 "고양이별로 간 아이". 지도·건강 경보·검색·홈 스포트라이트
  에서 제외하고, 상세에서는 돌봄 권유 대신 추모 안내를 보여준다. 입양 문의 버튼도 띄우지 않는다.
- **더미 고양이 134마리는 삭제하지 않는다**(초기 시딩 자산). 단 대외 자료(보도·지원사업 서류)에는
  실물 수치만 인용한다 — 전체 카운트에서 더미를 뺀 값.
- 좋아요(하트) = "지켜보기": 유저당 고양이 1회, 토글. `cats.like_count`는 트리거가 유지하는
  비정규화 값이라 직접 갱신하지 않는다.

## 돌봄 기록(care_logs)

- 7종 활동: 밥/물/간식/건강 체크/TNR/병원/쉼터(+기타). 기록 1건 = 돌봄 레벨 EXP +10.
- 제한: 유저당 분당 8건·일 120건(클라 검사 + DB 트리거 이중), `logged_at`은 미래 불가·24시간
  이내만. 비밀 기록(`is_private`)은 작성자 외 노출·알림 금지.
- 기록 시 알림: 고양이 주인(작성자 본인 제외) + 하트 누른 유저들(공개묘·비밀 아님·쿨다운 통과 시).
- 주간 지표 집계는 `care_logs` 기준(과거 checkin_days 기반이었으나 코인 폐지 때 재배선).

## 게임 요소 — 남긴 것과 폐지한 것

- **존치**: 돌봄 레벨(card_level/exp), 대표묘, 마커 아트, 케어 간식, 업적/타이틀, 쇼핑 포인트.
- **폐지(복원 금지)**: 카드 수집·배틀(2026-08-27), 다마고치·코인·일일출석·냥상자·코인상점
  (2026-08-29). 관련 코드를 되살리는 변경은 사장님 지시 없이는 하지 않는다.

## 서클 ("우리동네 길집사")

- 유저당 서클 1개(자동 생성, MVP). owner가 초대 → 상대 수락 시 `accepted` 멤버.
- 서클 멤버에게만 `circle` 가시성 고양이 핀이 보인다. 멤버가 되어도 멤버의 위치가 공유되는 것은
  아니다(핀 가시성만 넓어짐).
- 서클 채팅: 멤버 간 그룹 채팅. 사진은 비공개 저장(`private:` 참조) 후 멤버에게만 signed URL 발급.
  메시지 삭제는 본인 또는 owner만. 새 메시지 푸시는 서비스 필수 알림으로 취급(마케팅 동의 불요).
- 주소·위치로 보이는 텍스트는 공개 게시물에선 하드 차단, DM·서클 채팅에선 경고 후 허용.

## 커뮤니티·쪽지

- 게시글·댓글의 작성자 표시(author_name/avatar/level)는 **작성 시점 스냅샷** — 닉변 시 과거 글을
  소급 수정하지 않는다(비정규화 의도).
- 정지된 유저는 쓰기 전면 차단(`is_user_not_suspended`). 차단(블록)한 상대의 콘텐츠는 서로 숨김.

## 가입·계정

- 소셜(카카오/구글) + 이메일. 카카오톡 인앱 브라우저에서는 소셜 로그인이 차단되므로 안내 문구로
  외부 브라우저 유도. 첫 소셜 가입자는 닉네임 자동 생성(형용사+명사+3자리 숫자).
- 닉네임은 대소문자 무시 유일(unique). 가입 트리거는 충돌 시 접미사로 회피해야 한다 — 충돌로
  가입 자체가 실패하면 안 된다(2026-09-02 실사고).
- 가입 100번째까지 `early_supporter` 타이틀 자동 부여(이후 가입자는 없음).
- 약관 동의 시각(`terms_agreed_at`)은 최초 1회만 기록하고 이후 로그인에서 덮어쓰지 않는다
  (법적 동의 시점 보존).

## 쇼핑·포인트·후원

- **후원율 10%, 기준은 이익**: 후원액 = (판매가 − 매입가) × 수량 × 10%, 원 단위 내림. 대외 고지
  문구 "수익(이익)의 10%"와 1:1 대응하며, 판매액 기준으로 계산하면 고지와 어긋난다. 예외:
  `donation_percent`가 100 이상인 전액 후원 상품은 매입가와 무관하게 결제 금액 전액.
  매입가는 마진 정보라 서버 전용 테이블에 격리 — 클라이언트에서 후원액을 계산하지 않는다.
  (5%→10% 상향은 2026-08-17 확정, 대주산업 공문 5%와의 정합은 후속 과제이나 10%를 되돌리지
  않는다.) 구매자가 "내가 돌보는 고양이"를 후원 대상으로 우선 지정할 수 있다(집행 UI는 오픈 후
  착수).
- 구매 적립률 1/2/3%(등급별, 2026-08-30 하향 확정). 표시 문구는 설정값을 참조해야 하며 숫자를
  하드코딩하지 않는다.
- 부가세 표시 의무 준수(가격 표시에 세금 포함 여부 명확히).
- **가상상품은 사용 이력 확인 체계 전까지 review(판매 보류) 하드 가드** — 해제 조건은
  box/가상상품_등록전_선행조건.md 의 선행 조건 충족.
- 환불: 정책 로직은 `lib/refund-policy.ts`가 단일 소스. 실동작은 결제 오픈 이후. 부분환불 UI와
  게스트 동선은 의도적 보류 상태.

## 알림(푸시)

- 서비스 알림(댓글·쪽지·서클 채팅·돌봄 소식)은 구독만 있으면 발송. **마케팅 알림은
  `marketing_push_enabled` 동의자에게만.** 전원 강제 발송은 봉인(2026-08-12), 합법 상한
  35~50명 기준으로만 브로드캐스트.
- welcome 플로우에서 신규 가입자 전원이 알림 켜기 스텝을 한 번 통과한다(사장님 지시). 동의
  체크박스 사전 체크 금지(법적). iOS 미설치 환경은 알림 대신 홈 화면 추가 안내를 보여준다.

## 청원·행사

- 홈 청원 카드는 큐레이션 링크 방식: `PETITIONS` 상수에 항목 추가, 마감 지나면 자동 숨김,
  카피는 중립 유지. 서명 수집을 앱이 직접 하지 않는다.
