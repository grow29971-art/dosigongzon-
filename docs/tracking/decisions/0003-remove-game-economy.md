# 0003 — 게임 경제 전면 폐지 (2026-08-27 카드, 08-29 다마고치·코인)

## 배경

카드 수집·배틀, 다마고치, 코인·일일출석·냥상자·코인상점까지 게임화 레이어가 컸지만, 실측 결과
리텐션 기여가 없고(WAU 한 자릿수) 유지 비용만 컸다. 2026-07-16 브레인스토밍에서 이미 "게임 신규
투자 중단" 합의가 있었다.

## 결정

게임 경제를 전면 삭제(코드 -4,350줄, DB 정리 SQL 실행·검증 완료). 존치는 4가지뿐: 돌봄 레벨
(card_level/exp, 기록당 +10), 대표묘, 마커 아트, 케어 간식. 주간 지표 집계는 checkin_days에서
care_logs 기준으로 재배선.

## 검토한 대안

- **게임화 리뉴얼(재투자)** — 성공 사례 부재 + 코어(기록·돌봄) 검증이 먼저라 기각.
- **숨김 플래그로 보존** — 저활용 UI에는 쓰는 패턴이지만, 경제 시스템은 DB·크론·정산까지 얽혀
  유지 비용이 커서 완전 삭제 선택.

## 결과와 제약

- 폐지된 시스템의 복원은 불가에 가깝다(데이터 삭제됨) — "코인 다시 켜자"류 제안은 신규 설계로
  취급해야 한다.
- 돌봄 레벨 EXP 적립 RPC(`add_cat_card_exp`)는 이름에 card가 남아 있지만 살아 있는 경로다 —
  이름만 보고 지우면 안 된다.
- 쇼핑 포인트는 게임 코인과 무관한 별도 체계로 존치.
