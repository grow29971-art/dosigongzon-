# 0007 — 리디자인 「익숙한 동네앱」 — 순백 바탕·뉴트럴 그레이·Pretendard 단일·라운드 상한 12px (2026-09-16)

## 요약

2026-08-26 "D 아이보리 에디토리얼"(아이보리 바탕·웜 잉크·Noto Serif 제목·큰 라운드)을 폐기하고
당근·토스식 "익숙한 동네앱" 문법으로 전환한다: 순백 `#FFFFFF` 바탕, 뉴트럴 회색 스케일, Pretendard 단일 서체,
카드·시트 라운드 상한 12px, 그림자 대신 1px 헤어라인. primary 테라코타 `#B05C36`은 유지(CTA·활성·선택 전용).
이 문서 커밋이 revert 기준선이다 — 이후 `style:` 커밋 N개를 이 지점으로 되돌릴 수 있다.

## 배경

- 사장님이 8/13 토큰 수렴, 8/26 D 아이보리 에디토리얼을 거치고도 "전체 화면이 AI티가 나고 촌스럽다"를
  세 번째 제기(9/16). 진단: 촌스러움의 실체는 색·폰트가 아니라 화면 문법 5종 — 카드 안 카드·틴트 박스,
  전부 둥근 모서리, 한 화면 5색 이상, 길고 밀도 낮은 설명문, 실사 사진 부재.
- 같은 날 오전 대안 C 「시빅 포스터」(검정+라임·라운드 0·Gothic A1)를 8커밋으로 실제 배포했다가 실물
  확인 후 전체 되돌림(55c46c99). 오후에 대안 A 「익숙한 동네앱」으로 확정.

## 결정

1. **문법**: 당근·토스. 카드 → 헤어라인 섹션 + 구분선 리스트, 틴트 아이콘 박스 제거, 화면 구성 요소의
   이모지 전부 → lucide 선 아이콘(사용자 데이터 본문의 이모지는 무변경), 그라디언트·글로우 제거.
2. **색**: 순백 바탕, 뉴트럴 gray-50…900(본문·라벨 4.5:1 이상, muted는 글자 금지), primary 테라코타 유지,
   의미색(error·warning·like·care·sage)만. 커뮤니티 카테고리·호칭 배지는 회색 통일, **긴급만 빨강**.
   하드코딩 hex는 `app/**/*.tsx`에서 0(예외: 브랜드색 카카오 `#FEE500`·네이버 `#03C75A`, OG 이미지,
   `app/layout.tsx` theme-color, `app/darkcheck`, `app/api` 메일 템플릿, 약품 가이드 DB 기본값).
3. **형태**: 라운드 12(카드·시트·모달)/8(입력·버튼·썸네일)/6(칩)/원형(아바타·고양이 썸네일). 20px 이상
   라운드·필 남용 금지. 그림자는 FAB·바텀시트·모달·드롭다운에만.
4. **글씨**: Pretendard 단일. Noto Serif KR 로딩·토큰·클래스 제거. 제목 700.
5. **사진**: 고양이·사람 원형, 상품·게시글 8px. 사진 없는 고양이는 지도 마커 아트 SVG 재사용(사장님
   선택 — 다색 증가를 알고 고름, 회색 실루엣으로 바꾸지 말 것). `placehold.co` 앱 참조 제거.
6. **범위**: 사용자 화면·관리자 22페이지·랜딩·약관·숨김 섹션(SHOW_* false) 전부. 제외: OG 이미지 19종,
   주간 메일·관리자 알림 HTML, Android TWA 색, 지도 마커 아트, 첫 진입 오버레이 5종의 개수·조건.
7. **배포**: 브랜치에서 화면군마다 1커밋(단독 revert 가능), Vercel 프리뷰로 확인 후 main에 **1회 머지**.
