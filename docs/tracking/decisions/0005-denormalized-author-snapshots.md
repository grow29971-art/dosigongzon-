# 0005 — 작성자 정보 비정규화 스냅샷

## 배경

게시글·댓글·케어로그마다 작성자 표시(닉네임·아바타·레벨)가 필요하다. 정석은 profiles 조인이지만,
목록 화면마다 조인 비용이 들고 RLS 정책이 얽힌다.

## 결정

작성 시점의 author_name/avatar/level을 행에 스냅샷으로 저장한다. 닉네임을 바꿔도 과거 글은
작성 당시 이름으로 남는다(닉변의 자연스러운 동작으로 수용). cats.like_count도 같은 계열
(트리거 유지 비정규화 카운트).

## 검토한 대안

- **profiles 조인** — 목록 쿼리 비용 + profiles 락다운(anon 조회 차단)과 충돌해 기각.
  profiles가 잠겨도 글은 보여야 한다.

## 결과와 제약

- 스냅샷을 소급 갱신하거나 조인 구조로 정규화하는 리팩터링은 금지 — 2026-08-27 닉네임 중복 해소
  때도 과거 글 author_name은 의도적으로 건드리지 않았다.
- 표시 이름이 최신이어야 하는 화면(프로필 페이지 등)은 스냅샷이 아니라 profiles를 읽어야 한다 —
  두 값이 다른 것은 버그가 아니다.
