# 0008 — 앱인토스 입점: PWA 그대로 불가, 축소판 미니앱은 조건부 보류 (2026-09-17)

## 배경

사장님이 도시공존을 토스 앱 안(앱인토스)에 올리고 싶다고 했다 — "PWA 못 올리면 컨버전 해서라도".
앱인토스 개발자센터 문서(2026-09 기준)를 확인한 결과, 기존 웹앱을 URL로 등록하는 방식이 아니다.

## 확인한 사실 (개발자센터 문서 기준)

| 항목 | 앱인토스 규칙 | 도시공존 현재 |
|---|---|---|
| 배포 형태 | 정적 번들(`.ait`, 압축 해제 100MB↓)을 콘솔에 업로드 → `<appName>.web.tossmini.com`에서 토스가 호스팅. 외부 URL 등록 불가, iframe 금지 | Next.js SSR + API 라우트, Vercel |
| 렌더링 | CSR/SSG만, SSR 금지 | 대부분 서버 컴포넌트·SSR |
| 로그인 | 토스 로그인만("자사 로그인이나 기타 로그인 방식은 제공하지 않아요") | 카카오 OAuth + Supabase Auth |
| 결제 | 토스페이만("토스페이 외의 다른 결제 수단은 제공하지 않아요") | 토스페이먼츠 PG 계약심사 중 — 별개 상품 |
| 외부 이동 | 토스 도메인 밖으로 이동·외부 콘텐츠 렌더 불가 | 카카오맵 SDK·오픈채팅·청원 링크 |
| UI | 라이트 모드 고정, 진입 시 바텀시트 금지, 모든 화면 뒤로가기 필수 | 리디자인이 라이트 기준 |
| 기존 회원 | "기존 서비스의 회원 식별자(userKey)를 토스 로그인과 똑같이 설정" 가능 | 카카오 계정 ↔ 토스 계정 매핑 규칙 미확인 |
| 심사 | 콘솔 테스트 → 검토 요청 → 영업일 3일(카테고리에 따라 7일+) | — |

## 결정

1. **PWA/TWA 래핑 방식은 없다.** "컨버전"은 별도 클라이언트(Vite/React SPA + `@apps-in-toss/web-framework`)를
   새로 만드는 일이며, 백엔드(Supabase·API 라우트)만 재사용된다.
2. **지금은 코드 착수하지 않는다.** PMF 진단(0003 이후, 2026-08-29)의 "인터뷰 3명 전 3커밋 초과 변경 금지"와
   충돌하고, 축소판만으로도 2~3주(인증 브릿지가 절반)다. WAU 한 자릿수에서 채널을 늘려도 "쓸 이유"가
   검증되지 않으면 깨진 독이다(0724 성장회의 결론과 동일).
3. **코드 0줄로 되는 준비는 지금 한다**: 콘솔 가입·워크스페이스 개설·사업자 인증, 그리고 아래 질의를 토스에
   보낸다.
4. **착수 조건**: 월동 인터뷰에서 "지도(고양이 핀·돌봄 기록) 하나면 쓴다"는 응답이 나오면 축소판 착수.
   그때 범위는 지도+돌봄 기록만이고 커뮤니티·서클·쇼핑은 제외한다.

## 사전 질의 목록 (토스 앱인토스 콘솔/문의)

- 카카오맵 JS SDK(외부 스크립트·타일 로드)가 "외부 콘텐츠 렌더 불가" 조항에 걸리는지 — 심사 사례.
- 기존 카카오 가입 회원을 토스 로그인 userKey에 매핑할 때 허용되는 키(CI·전화번호·이메일) —
  이메일은 토스 가입 필수가 아니라 null일 수 있음.
- 실물 상품(사료) 판매를 미니앱 안에서 열 때 토스페이 IAP 계약이 토스페이먼츠 PG 계약과 별개인지.
- 위치 권한 없이(퍼징 좌표만) 지도 서비스가 심사 통과 가능한지 — 우리는 정확 좌표를 받지 않는다(0001).

## 착수 시 설계 메모 (지금 만들지 않음)

- 인증: 토스 로그인 인가코드 → 우리 서버(API 라우트)에서 교환·복호화 → Supabase 커스텀 세션 발급.
  개인정보처리방침에 토스 로그인 항목·계정 연결 기준 추가 필요.
- 위치 계약(0001)은 그대로: 등록 시 클라이언트 ±444m 오프셋, 비로그인 +500m — 미니앱은 항상 로그인
  상태이므로 +500m 경로는 없음.
- 미니앱 도메인(`tossmini.com`)을 Supabase Auth redirect·CORS·카카오맵 허용 도메인에 추가.
- 쇼핑은 첫 판에 넣지 않는다. 넣는 시점엔 토스페이 IAP 별도 연동.

## 결과와 제약

- 이 결정은 "안 한다"가 아니라 "인터뷰 결과 전엔 안 한다"다. 재론 트리거는 인터뷰 응답이며,
  노출 수(3,000만)는 트리거가 아니다.
- 기존 앱을 손대서 앱인토스 규칙(SSR 제거·토스 로그인 전용)에 맞추는 방향은 금지 — 본 앱의 카카오
  로그인·SSR·쇼핑 PG는 그대로 두고 미니앱을 별도로 만든다.
