# 0006 — 앱명 "도시공존" 유지, "우리동네 길집사"는 기능명으로 (2026-08-28 / 09-02)

## 배경

2라운드 네이밍 원탁회의가 "우리동네 길집사"(축약 "길집사")를 신규 서비스명으로 확정했었다.
로고 락업·스토어 타이틀·표기 시스템까지 설계 완료 상태에서, 같은 날 사장님이 번복했다.

## 결정

앱명은 "도시공존" 현행 유지. 회의 자산은 폐기하지 않고 보존했다가, 2026-09-02에
"우리동네 길집사"를 **서클 기능의 사용자 노출 이름**으로 재사용했다(구 Private Circle 표기 전면
교체). 기업·상표·법적 주체·도메인은 어떤 안에서도 "도시공존"으로 불변이었다.

## 검토한 대안

- **서비스명 전면 교체** — 토스 심사 중 서비스명 변경은 재심사 트리거 리스크 + 리브랜딩 비용으로
  보류(기각이 아니라 사장님 의사로 취소).

## 결과와 제약

- 코드의 "도시공존" 표기 409곳 중 상호·법적 표기(판매자 정보·약관 회사 정의·결제 표기)는 어떤
  리네이밍에서도 남겨야 한다 — 일괄 치환 금지.
- "우리동네 길집사"는 이제 서클 기능을 가리킨다 — 앱 전체 이름으로 쓰면 혼동을 만든다.
- 약관의 기능 목록은 "우리동네 길집사(구 Private Circle)"로 병기해 법적 연속성을 유지한다.
