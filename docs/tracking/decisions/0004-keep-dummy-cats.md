# 0004 — 더미 고양이 유지 + 대외 인용 분리 (2026-08)

## 배경

전체 고양이의 절반가량(134마리)이 초기 시딩용 더미다. "정직하게 지우자"는 제안이 있었지만,
빈 지도는 신규 방문자에게 죽은 서비스로 보인다.

## 결정

더미는 삭제하지 않는다. 대신 **대외 자료(보도·지원사업·IR)에는 실물 수치만 인용**해 정직성을
지킨다. 앱 내 카운트는 전체 수를 보여줘도 된다.

## 검토한 대안

- **전량 삭제** — 지도·랜딩의 사회적 증명이 무너져 기각.
- **더미 뱃지 표시** — "가짜가 섞였다"는 인상만 강화해 기각.

## 결과와 제약

- 외부 제출 문서를 쓸 때는 매번 실물/전체를 구분해 집계해야 한다(전체 수 복붙 금지).
- 더미 사진·데이터를 참조하는 코드가 있으므로 일괄 삭제 스크립트를 돌리면 안 된다.
